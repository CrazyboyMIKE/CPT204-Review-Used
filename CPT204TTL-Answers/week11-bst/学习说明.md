# Week 11 中文学习说明：Binary Search Tree

本周 BST 题目考得很典型：判断合法性、插入顺序影响高度、搜索路径、遍历、计数和删除。

## 1. BST 合法性

BST 规则不是只看父子节点，而是看整棵子树：

- 左子树所有节点都必须小于当前节点。
- 右子树所有节点都必须大于当前节点。

代码使用上下界检查。进入左子树时，上界变成当前节点；进入右子树时，下界变成当前节点。

题图中如果 75 放在 90 的右孩子位置，它违反 BST，因为 75 小于 90 却在右边。正确位置应在 90 的左边，或根据整棵树范围放到合法位置。

## 2. 插入顺序影响树形

顺序 A：

```text
10, 20, 30, 40, 50, 60
```

会形成一路向右的链，最大比较次数是 6。

顺序 B：

```text
40, 20, 60, 10, 30, 50
```

更平衡，最大比较次数是 3。

BST 查找复杂度是 `O(height)`，所以树越矮越好。

## 3. 搜索 42 的路径

在树 `50, 30, 80, 20, 40, 45, 70, 90` 中找 42：

```text
50 -> 30 -> 40 -> 45
```

到 45 后，42 小于 45，所以应该去 45 的左子树。如果左子树为空，就能确定 42 不存在，不需要检查其他子树。

## 4. 遍历

给定树：

```text
        50
       /  \
     30    80
    / \   /  \
  20  40 70  90
        \
        45
```

Inorder：

```text
20, 30, 40, 45, 50, 70, 80, 90
```

Preorder：

```text
50, 30, 20, 40, 45, 80, 70, 90
```

BST 的 inorder traversal 会得到排序结果。

## 5. `countGreaterThan`

如果当前节点 `<= target`，左子树一定更小，不可能有答案，可以直接去右子树。

如果当前节点 `> target`，当前节点要计数，并且左右子树都可能还有更大的节点。

## 6. 删除有两个孩子的节点

常见做法：用左子树最大节点替换当前节点。

步骤：

1. 从 `current.left` 开始。
2. 一直沿着 `.right` 找到最大节点 `rightMost`。
3. 把 `rightMost.element` 复制到 `current.element`。
4. 删除原来的 `rightMost` 节点。

注意不能写 `current = rightMost`，因为那只是改变局部变量，不会修改树结构。
