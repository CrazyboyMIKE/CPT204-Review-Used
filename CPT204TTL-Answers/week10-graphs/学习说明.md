# Week 10 中文学习说明：图、带权边、Prim、Dijkstra 与路径恢复

本周图论题目以概念为主，代码重点是邻接矩阵和 `parent` 数组路径恢复。

## 1. True / False

1. An edge in an undirected graph is bidirectional.  
   答案：True。无向边可以从两个方向理解。

2. A weighted graph is a graph in which each vertex is assigned a numeric weight.  
   答案：False。带权图通常是边有权重，不是顶点有权重。

3. A tree is a connected graph with no cycles.  
   答案：True。这是树的经典定义。

4. In a connected graph, every pair of vertices must be directly connected by an edge.  
   答案：False。连通只要求任意两点之间存在路径，不要求必须有直接边。

## 2. 带权边 `{1, 2, 2}` 的含义

它表示从顶点 1 到顶点 2 有一条权重为 2 的边。如果图是无向图，也表示从 2 到 1 权重为 2。

邻接矩阵中：

- 有边的位置存 weight。
- 没有边的位置可以用 `null` 或无穷大表示。
- 无向图矩阵是对称的。

## 3. Prim 和 Dijkstra 的区别

Prim 用来求最小生成树。`cost[v]` 表示：把顶点 `v` 接入当前生成树集合所需的最小边权。

Dijkstra 用来求单源最短路径。`cost[v]` 表示：从源点到 `v` 的当前最短总距离。

所以更新公式不同：

- Prim：只看边权 `weight(u, v)`
- Dijkstra：看路径总长 `cost[u] + weight(u, v)`

## 4. `parent` 数组恢复路径

`parent[v]` 表示路径中 `v` 的上一个节点。从目标节点一直往父节点追溯，会得到反向路径。

例如：

```text
parent[4] = 2
parent[2] = 1
parent[1] = 0
parent[0] = -1
```

反向得到 `4 -> 2 -> 1 -> 0`，翻转后是：

```text
0 -> 1 -> 2 -> 4
```
