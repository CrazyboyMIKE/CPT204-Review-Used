# Week 09 中文学习说明：排序、堆与泛型排序

本周包括手算题和代码题。排序题要特别注意“每一轮结束后数组状态”和“比较条件如何改变排序方向”。

## 1. Bubble Sort 第三轮结果

初始数组：

```text
[2, 9, 5, 4, 8, 1]
```

第一轮后，最大值 9 到最后：

```text
[2, 5, 4, 8, 1, 9]
```

第二轮后，8 到倒数第二：

```text
[2, 4, 5, 1, 8, 9]
```

第三轮后，5 到正确位置：

```text
[2, 4, 1, 5, 8, 9]
```

## 2. Bubble Sort 优化

普通冒泡排序即使数组已经有序，也会继续做所有轮。优化版加入 `swapped`：

- 本轮发生交换：继续下一轮。
- 本轮没有交换：数组已经有序，提前停止。

最好情况是已排序数组，只需要一轮扫描，复杂度 `O(n)`。

## 3. 最大堆未知值

最大堆要求父节点 `>=` 子节点。未知节点的父节点是 30，子节点是 26 和 27。

所以未知值 `x` 必须满足：

```text
30 >= x >= 27
```

如果只考虑整数，可能值是：

```text
27, 28, 29, 30
```

共有 4 个。

## 4. 降序 Quick Sort

升序 quick sort 分区后是左小右大。降序时要反过来：

- pivot 左边：`>= pivot`
- pivot 右边：`<= pivot`

所以代码中的比较符号也要反过来。

## 5. 泛型 Merge Sort

`mergeSort(E[] values)` 要求 `E extends Comparable<E>`，因为要调用 `compareTo`。

如果传入 `Comparator<? super E>`，就可以让调用者自定义排序规则。

Merge Sort 特点：

- 时间复杂度 `O(n log n)`
- 额外空间 `O(n)`
- 稳定排序

## 6. 泛型 Insertion Sort

Insertion Sort 从第二个元素开始，把当前元素插入前面已经有序的部分。

特点：

- 最坏 `O(n^2)`
- 最好已排序 `O(n)`
- 对小数组或基本有序数组很有效
