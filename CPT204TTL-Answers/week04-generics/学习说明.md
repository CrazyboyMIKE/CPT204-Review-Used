# Week 04 中文学习说明：泛型与通配符

本周是 Java 泛型核心。考试通常会考“代码能不能编译”和“为什么要用某个通配符”。

## 1. 泛型方法 `<E>`

`reverse(ArrayList<E> list)` 和 `shuffle(ArrayList<E> list)` 都不关心元素具体类型，只需要交换位置。因此它们可以写成泛型方法。

`<E>` 放在返回值前面，表示这个方法声明了一个类型参数。

## 2. 泛型上界

`max(ArrayList<E> list)` 需要调用 `compareTo`，所以必须限制 E：

```java
public static <E extends Comparable<E>> E max(ArrayList<E> list)
```

这句话的意思是：E 必须实现 `Comparable<E>`，否则编译器不允许调用 `compareTo`。

## 3. 多类型 Pair

`Pair<E>` 只能让两个字段同类型。改成 `Pair<F, S>` 后，first 和 second 可以是不同类型，例如 `Pair<String, Integer>`。

泛型类型参数名字不重要，重要的是含义清楚。

## 4. 为什么 `ArrayList<Integer>` 不是 `ArrayList<Object>`

Java 泛型是不变的。虽然 `Integer` 是 `Object` 的子类，但 `ArrayList<Integer>` 不是 `ArrayList<Object>` 的子类。

原因是安全性：如果允许把 `ArrayList<Integer>` 当成 `ArrayList<Object>`，就可能往里面加入字符串，破坏整数列表。

如果只是读取打印，用：

```java
ArrayList<?>
```

## 5. `extends` 和 `super`

通配符口诀：PECS。

- Producer Extends：如果 source 只负责生产/读取，用 `? extends T`
- Consumer Super：如果 target 只负责消费/写入，用 `? super T`

因此复制方法写成：

```java
copy(ArrayList<? extends T> source, ArrayList<? super T> target)
```

## 6. 泛型限制

常见考点：

- 泛型只接受引用类型，不能用 primitive type。
- 泛型主要提供编译期类型检查。
- 编译后会发生类型擦除。
- 因为类型擦除，不能直接 `new T()`。
- `GenericStack<Integer>` 不是 `GenericStack<Number>` 的子类。
