# Week 12 中文学习说明：AVL 旋转与哈希探测

本周题目集中在 AVL 平衡旋转和开放定址哈希。AVL 要会看 balance factor；哈希要会一步步算探测位置。

## 1. LL rotation，且 `BF(B) = 0`

旋转前：

```text
    A
   /
  B
 / \
C   D
```

右旋后：

```text
    B
   / \
  C   A
     /
    D
```

变化：`B` 上升为根，`A` 变成 `B` 的右孩子，`D` 变成 `A` 的左孩子。

## 2. RR rotation，且 `BF(B) = 0`

旋转前：

```text
A
 \
  B
 / \
C   D
```

左旋后：

```text
    B
   / \
  A   D
   \
    C
```

变化：`B` 上升为根，`A` 变成 `B` 的左孩子，`C` 变成 `A` 的右孩子。

## 3. 插入 `60, 25, 80, 10, 40, 35`

插入 35 后，旋转前：

```text
      60
     /  \
   25    80
  /  \
10   40
     /
    35
```

第一个失衡节点是 60。60 左重，但它的左孩子 25 右重，所以是 LR case。

先对 25 左旋，再对 60 右旋，结果：

```text
      40
     /  \
   25    60
  / \      \
10  35     80
```

中序遍历仍然有序：

```text
10, 25, 35, 40, 60, 80
```

## 4. 线性探测

表长 `N = 13`，插入 `26, 39, 52, 14, 27`。

哈希位置：

```text
26 % 13 = 0
39 % 13 = 0
52 % 13 = 0
14 % 13 = 1
27 % 13 = 1
```

最终：

```text
index 0 = 26
index 1 = 39
index 2 = 52
index 3 = 14
index 4 = 27
```

会形成 primary clustering。

## 5. 二次探测

插入 `26, 39, 52, 65`，它们初始位置都是 0。

探测序列：

```text
0, 1, 4, 9, ...
```

最终：

```text
index 0 = 26
index 1 = 39
index 4 = 52
index 9 = 65
```

因为初始位置相同，探测序列也相同，所以仍有 secondary clustering。

## 6. 双重哈希

第二哈希函数：

```text
h2(key) = 5 - key % 5
```

插入 `26, 39, 52, 65`：

```text
26 -> index 0
39 -> index 1
52 -> index 3
65 -> index 5
```

双重哈希比二次探测更能减少 secondary clustering，因为不同 key 可以有不同步长。

## 7. balancePath 示例

插入 `70, 30, 90, 20, 50, 45` 后，插入节点 45 的路径是：

```text
70 -> 30 -> 50 -> 45
```

`balancePath` 会从底向上检查：

```text
45, 50, 30, 70
```

第一个失衡节点是 70，属于 LR case。旋转后：

```text
      50
     /  \
   30    70
  / \      \
20  45     90
```
