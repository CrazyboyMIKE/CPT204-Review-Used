# Week 05 中文学习说明：Todo 系统中的 List、Queue、Stack 与 PriorityQueue

本周把集合类放到一个 Todo 管理系统里。你要理解每种数据结构“适合解决什么问题”。

## 1. `List<Task>`：保存全部任务

`ArrayList` 适合保存完整任务列表，因为它能按插入顺序遍历所有任务。添加任务用 `add`，查看任务用循环，编辑和删除时先通过 `id` 找到任务。

本项目给每个任务分配 `id`，是为了避免两个任务标题相同导致无法区分。

## 2. 按状态显示任务

`printTasksByStatus(boolean completed)` 遍历全部任务，只输出 `isCompleted()` 等于目标状态的任务。

这个操作时间复杂度是 `O(n)`，因为必须看每个任务是否符合条件。

## 3. `Queue<Task>`：FIFO 任务处理

队列遵守 First In, First Out：

- `offer`：加入队尾
- `peek`：查看队头，不删除
- `poll`：取出队头并删除

适用于“谁先进入处理队列，谁先被处理”的场景。

## 4. `Stack<String>`：最近活动历史

栈遵守 Last In, First Out：

- `push`：记录新活动
- `peek`：查看最近活动
- `pop`：取出最近活动

本项目把添加、编辑、删除、完成、加入队列、处理队列等操作都记入历史。

## 5. `PriorityQueue<Task>`：优先级调度

优先队列不按进入顺序处理，而是按优先级处理。代码中优先级顺序是：

```text
HIGH -> MEDIUM -> LOW
```

如果两个任务优先级相同，再按 `id` 排序，让结果稳定。

## 6. FIFO 与 Priority 的区别

FIFO 队列关注公平性：先来先处理。

优先队列关注重要性：高优先级先处理。

考试解释时可以举例：普通排队适合 FIFO；急诊、系统调度、重要任务处理更适合 PriorityQueue。

## 7. 本项目怎么运行

进入本周目录后执行：

```bash
javac -encoding UTF-8 src/Week05Answers.java
java -cp src Week05Answers
```

运行结果会展示添加任务、编辑任务、完成任务、FIFO 处理、优先级处理和历史记录。
