# Week 03 中文学习说明：抽象类、接口、Comparable 与深拷贝

本周开始从“会写类”进入“会设计类型关系”。考试常考点是：什么时候用抽象类，什么时候用接口，`Comparable` 怎么排序，浅拷贝和深拷贝有什么区别。

## 1. ArrayList 洗牌

`shuffle(ArrayList<Number> list)` 使用 Fisher-Yates 算法。每一轮把当前位置 `i` 和前面随机位置 `j` 交换。

优点：

- 时间复杂度 `O(n)`
- 原地打乱，额外空间 `O(1)`
- 每种排列概率相同

## 2. ComparableCircle

`ComparableCircle extends Circle implements Comparable<ComparableCircle>` 同时体现继承和接口：

- `extends Circle`：复用半径和面积逻辑。
- `implements Comparable`：让对象具备比较能力。

`compareTo` 的规则：

- 返回正数：当前对象更大
- 返回负数：当前对象更小
- 返回 0：两者相等

## 3. 深拷贝 MyStack

浅拷贝只复制对象外壳，内部引用仍然共享；深拷贝要复制内部容器和容器里的可变对象。

代码中 `MyStack<T extends Copyable<T>>` 要求元素实现 `copy()`，因为 Java 无法可靠地自动复制任意对象。这样做的好处是：拷贝后的栈和原栈互不影响。

## 4. 抽象 Employee

`Employee` 是抽象类，因为它能保存员工通用字段 `name` 和 `id`，但不知道具体薪资公式。

`FullTimeEmployee` 返回固定月薪；`PartTimeEmployee` 返回 `hoursWorked * hourlyRate`。这就是多态：同样调用 `calculateSalary()`，不同子类给出不同实现。

## 5. Discountable 接口

接口表达“能力”。`Book implements Discountable` 说明 Book 可以计算折扣价。

继承和接口的区别：

- 继承回答“是什么”：Book 是 Product。
- 接口回答“能做什么”：Book 能计算 discounted price。

## 6. 抽象类 vs 接口常考点

- 抽象类不能直接实例化。
- 类继承类用 `extends`。
- 类实现接口用 `implements`。
- 普通子类必须实现所有抽象方法。
- 接口字段默认是 `public static final`。
- 重写方法不能降低可见性。

## 7. Student Comparable

`StudentMark.compareTo` 先比较 `mark`，同分时比较 `name`。排序题最重要的是先把“排序规则”说清楚，再写 `compareTo`。

## 8. Number 数组

`Integer`、`Double`、`Long`、`Float` 都是 `Number` 的子类。通过 `doubleValue()` 可以统一转成 `double` 做求和。

这题考多态和包装类继承关系。
