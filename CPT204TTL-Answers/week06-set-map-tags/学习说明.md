# Week 06 中文学习说明：Set、Map、标签与频率统计

本周继续 Todo 系统，但重点从线性结构转到哈希结构。`Set` 用来去重，`Map` 用来建立键到值的映射。

## 1. 每个任务的标签：`Set<String>`

每个 `Task` 内部有：

```java
Set<String> tags = new HashSet<>();
```

`HashSet` 的特点是元素不重复。给同一个任务添加两次 `"study"`，第二次不会改变集合。

## 2. 全局标签集合：`allTags`

`allTags` 保存系统中出现过的所有不同标签。它也是 `HashSet`，所以适合回答“现在一共有多少种标签”。

注意：删除任务或删除标签时，需要同步更新 `allTags`。代码通过 `tagFrequency` 判断某个标签是否还被其他任务使用。

## 3. 任务查找：`Map<Integer, Task>`

`taskMap` 的 key 是任务 ID，value 是任务对象。

通过 ID 查找任务：

```java
taskMap.get(id)
```

平均时间复杂度是 `O(1)`，比遍历整个任务列表的 `O(n)` 更快。

## 4. 标签频率：`Map<String, Integer>`

`tagFrequency` 记录每个标签出现在多少个任务里。

添加标签时：

```text
frequency = old frequency + 1
```

删除标签或任务时：

```text
frequency = old frequency - 1
```

如果频率降到 0，就从 `tagFrequency` 和 `allTags` 中删除。

## 5. 按标签过滤

当前 Week 06 的过滤方式是遍历所有任务，然后检查每个任务是否包含目标标签。复杂度是 `O(n)`。

Week 08 会进一步优化成标签索引：从标签直接找到任务 ID 集合。

## 6. 排序视图：`TreeSet` 和 `TreeMap`

`HashSet` 和 `HashMap` 不保证顺序。如果要按字母排序输出标签，可以临时构造：

```java
new TreeSet<>(allTags)
new TreeMap<>(tagFrequency)
```

这样可以在不改变主数据结构的情况下得到排序结果。
