# Week 02 中文学习说明：对象建模、继承、多态与 BigInteger

本周题目把 Week 01 的类设计扩展到继承、抽象建模和更复杂的计算。重点不是死背代码，而是理解“对象应该保存什么状态、提供什么行为”。

## 1. MyPoint

`MyPoint` 表示二维点，核心公式是欧几里得距离：

```text
sqrt((x1 - x2)^2 + (y1 - y2)^2)
```

实例方法 `distance(MyPoint other)` 使用当前对象；静态方法 `distance(MyPoint p1, MyPoint p2)` 不依赖某个对象。

## 2. Circle2D

圆相关判断都依赖圆心距离：

- 点在圆内：点到圆心距离 `<= radius`
- 一个圆包含另一个圆：圆心距离 + 小圆半径 `<=` 大圆半径
- 两圆重叠：圆心距离 `<=` 两个半径之和

这类题目要先画图，再把几何关系翻译成公式。

## 3. BigInteger

普通 `long` 放不下 50 位整数，所以必须使用 `BigInteger`。`BigInteger` 是不可变对象，加法、取模都返回新对象，例如 `current.add(BigInteger.ONE)`。

判断能否被 2 或 3 整除：

```text
number mod 2 == 0 或 number mod 3 == 0
```

## 4. Triangle 与 GeometricObject

`Triangle extends GeometricObject` 表示 Triangle 是一种 GeometricObject。父类保存通用属性，例如 `color` 和 `filled`；子类保存三条边，并实现面积与周长。

三角形面积使用海伦公式：

```text
s = (a + b + c) / 2
area = sqrt(s(s-a)(s-b)(s-c))
```

## 5. Person 继承体系

这题考多态：`Person[]` 数组可以保存 `Person`、`Student`、`Employee`、`Faculty`、`Staff` 对象。循环调用 `toString()` 时，Java 会根据对象真实类型执行对应版本。

题目问 `Person` 中 `name` 的访问修饰符：如果子类需要直接访问，可以用 `protected`；如果追求更严格封装，实践中更推荐 `private` 加 getter。

## 6. MyStack

栈的规则是 LIFO：Last In, First Out。`push` 把元素放到末尾，`pop` 从末尾取出并删除，`peek` 只看末尾不删除。

本题要求继承 `ArrayList<Object>`，因此代码这样写。但真实项目中更推荐组合：在 `MyStack` 内部保存一个 `ArrayList` 字段，避免暴露太多父类方法。

## 7. Tax

税率计算是边际税率，不是把全部收入乘以最高税率。比如某个收入跨过多个 bracket，每一段只按自己的 rate 计算。

`Tax.getTax()` 的思路是：

1. 根据 `filingStatus` 找到对应 brackets。
2. 从低档到高档逐段累加。
3. 如果当前收入落在某一档内部，只计算该档剩余部分，然后返回。
