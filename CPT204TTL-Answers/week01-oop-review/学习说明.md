# Week 01 中文学习说明：数组、类与对象基础

本周重点是把 Java 基础语法转成可运行的小程序：数组遍历、原地修改、简单类设计、对象方法、`toString()`、比较逻辑和基础性能计时。

## 1. 原地反转数组

`reverseInPlace(double[] values)` 使用双指针。左指针从数组头部开始，右指针从数组尾部开始，每次交换一对元素。因为直接改原数组，所以额外空间复杂度是 `O(1)`；每个元素最多被访问一次，时间复杂度是 `O(n)`。

关键理解：原地算法不返回新数组，而是修改传入的数组对象。Java 数组是引用类型，方法内部改动数组内容，调用者也能看到变化。

## 2. 四个连续相同值

`isConsecutiveFour(int[] values)` 判断是否存在 `values[i] == values[i+1] == values[i+2] == values[i+3]`。循环终点是 `values.length - 4`，因为最后不足四个元素的位置不可能形成四连。

只要找到一次满足条件的连续四个值，就可以直接 `return true`，不需要继续检查。

## 3. 最长连续段

`longestRun(int[] values)` 维护两个变量：

- `currentRun`：当前连续相同段的长度。
- `bestRun`：到目前为止见过的最大连续段长度。

如果当前元素等于前一个元素，`currentRun++`；否则当前连续段断开，`currentRun = 1`。空数组返回 `0`。

## 4. StopWatch 与选择排序

`StopWatch` 用 `System.currentTimeMillis()` 记录开始和结束时间。`selectionSort` 每轮从剩余元素中找最小值放到前面，时间复杂度是 `O(n^2)`。

选择排序适合本题演示计时，因为它实现简单，而且数据量增大时运行时间变化明显。

## 5. Student 与 Book 类

这两题训练类设计：

- 字段用 `private`，避免外部随意修改对象状态。
- 构造器负责初始化必要数据。
- `toString()` 负责把对象转成可读文本。
- `less(...)` 根据题目指定属性比较对象。

`Student.less` 比较 `groupNumber`；`Book.less` 比较 `year`。

## 6. Assign Grades

先遍历所有分数找到 `best`，再按照题目区间分配等级：

- `score >= best - 10` 是 A
- `score >= best - 20` 是 B
- `score >= best - 30` 是 C
- `score >= best - 40` 是 D
- 其他是 F

判断必须从 A 到 F，因为高等级条件更严格。

## 7. Stock 类

`Stock` 题目考察字段、构造器、setter 和计算方法。涨跌百分比公式是：

```text
(currentPrice - previousClosingPrice) / previousClosingPrice * 100
```

如果结果是负数，表示价格下降。
